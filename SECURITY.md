# Security policy

## Reporting a vulnerability
Please do not open a public issue for a security problem. Use the "Report a vulnerability" button on this repository's Security tab, which sends a private report.

## What to expect
This is a small personal project. I will aim to reply within two weeks.

## Supported versions
Only the latest version on the main branch.

## Data
The toolkit processes files on your own computer and does not send data anywhere. Please never include real donor or employee data in a report or issue.
